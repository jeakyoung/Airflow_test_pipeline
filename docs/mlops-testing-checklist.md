# MLOps Testing Checklist

`test_pipeline` DAG으로 기본 실행(성공 케이스 1회)은 확인됨. 아래는 실제 ML 파이프라인에 필요한 동작을 검증하기 위해 추가로 테스트/구현해봐야 할 항목. 우선순위 순으로 정리.

- [ ] **1. 실패/재시도 동작**
  태스크를 일부러 실패시켜서 `retries`/`retry_delay` 설정대로 재시도하는지, 최종 실패 시 알림(Slack/이메일)이 가는지 확인.

- [ ] **2. 멱등성(idempotency) / 재실행 안정성**
  같은 DAG run을 다시 트리거했을 때 결과가 중복되거나 달라지지 않는지 확인. 재현성의 핵심.

- [ ] **3. 조건부 분기 (모델 승격 게이트)**
  `BranchPythonOperator`로 "평가 지표 ≥ 기준치면 배포, 아니면 중단" 패턴 구현. 자동 승격/롤백 로직의 기본형.

- [ ] **4. 외부 의존성 대기 (Sensor)**
  새 데이터가 준비될 때까지 기다렸다가 다음 단계로 넘어가는 데이터-기반 트리거 패턴 구현.

- [ ] **5. 병렬/동적 태스크 (하이퍼파라미터 스윕)**
  Dynamic Task Mapping으로 여러 조합을 동시에 실행, `pool`로 동시성 제한 시 큐잉이 정상 동작하는지 확인.

- [ ] **6. 큰 아티팩트 처리**
  모델 파일 등 큰 결과물을 XCom으로 넘기지 않고 외부 스토리지(S3 등)에 저장 후 경로만 전달하는 패턴 검증.

- [ ] **7. DAG 코드 자체의 테스트**
  `tests/`에 pytest로 "import 에러 없음", "순환 의존성 없음", "필수 태그/owner 존재" 등 정적 검증 추가, CI 연동.
